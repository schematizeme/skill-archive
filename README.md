# schematize-archive

O archive da casa como criticidade 0: rege o `<projeto>_archive/` obrigatório (checklists, planos, ADRs, handoffs, índice/MAPA, relatórios de audit).

Gera afazeres para o overdev a partir do histórico recuperável (`/archive-todos`) e materializa a estrutura do archive (`/archive-init`).
